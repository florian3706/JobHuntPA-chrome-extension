How to get a key
  1. In JobHuntPA open Settings, then Browser extension, then Connect a browser extension.
  2. Copy the server address and the extension key shown there (the key is shown only once).
  3. Paste both below and press Connect. The browser asks whether this extension may talk to your server; allow it.

http://127.0.0.1:8000 on the same computer; from other devices, the https:// address Tailscale or your proxy gives it, such as https://my-pc.tailnet.ts.net.

When already connected, paste a key only to replace the saved one; Connect alone tries the saved key again.

Reset this browser's setup

Removes the server address, the key and the chosen workspace from this browser, and withdraws the permission for your server. The key itself keeps working until you disconnect this extension in JobHuntPA (Settings, Browser extension); do that too if the device is lost.

Remove the whole setup from this browser? To use the extension again you connect it with a new key from JobHuntPA.
