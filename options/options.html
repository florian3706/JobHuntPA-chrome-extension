JobHuntPA extension

Add the page you are looking at to your own JobHuntPA server: a job, the jobs on a page of search results, or a company source.

How to connect

  1. In JobHuntPA open Settings, then Browser extension, then Connect a browser extension.
  2. Copy the server address and the extension key shown there (the key is shown only once).
  3. Paste both below and press Connect. The browser asks whether this extension may talk to your server; allow it.

For example http://127.0.0.1:8000, http://raspberrypi.local:8000 or https://my-pc.tailnet.ts.net.

You can also switch workspace in the extension's popup.

Reconnect or reset

Reconnect: press Connect above to try the saved key again, or first paste a new key or another server address.

Reset: removes the server address, the key and the chosen workspace from this browser, and withdraws the permission for your server. The key itself keeps working until you disconnect this extension in JobHuntPA (Settings, Browser extension); do that too if the device is lost.

Remove the whole setup from this browser? To use the extension again you connect it with a new key from JobHuntPA.
